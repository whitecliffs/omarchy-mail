# Security policy

Omarchy Mail handles email credentials, OAuth tokens, message content, and
optional iCloud credentials. Please do not report a suspected vulnerability in
a public issue or Discord message.

For now, report security issues privately to the repository maintainer through
the GitHub account that owns this project. Include a concise description, the
affected version or commit, reproduction steps, and the smallest useful
technical details. Remove real credentials, tokens, message contents, and
personal calendar URLs from reports.

The application is community software and has not undergone an independent
security audit. Review the code and package source before using it with an
important mailbox.
